# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

To report a vulnerability in MediaGarrd, please send an email to devsecinsider@gmail.com.
This report should contain a detailed explanation of the vulnerability that was found, as well
as details about the attack surface/scope. Do not send more than one report for the same vulnerability.
